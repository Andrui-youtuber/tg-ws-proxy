# 🚀 TG WS Proxy для Termux

Локальный MTProto-прокси для Telegram, который запускается прямо на Android через Termux. Установка одной командой.

> Основан на проекте [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) (лицензия MIT). Здесь только установщик и удобный запуск для Termux.

---

## 📋 Что нужно

- Android-телефон
- [Termux](https://f-droid.org/packages/com.termux/) (скачивай с F-Droid или GitHub, версия из Google Play устарела)
- Интернет

---

## ⚡ Установка

Открой Termux и вставь команду:

```bash
pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/ТВОЙ_НИК/ИМЯ_РЕПО/main/install.sh | bash
```

Подожди пару минут. В конце появится надпись **«Готово»**.

---

## ▶️ Запуск

```bash
tgp
```

На экране появятся настройки для Telegram и ссылка для быстрого подключения.

---

## 🔗 Подключение к Telegram

**Способ 1: автоматически**

Нажми на ссылку `tg://proxy?...` из окна Termux или выполни:

```bash
tgp link
```

Telegram откроется сам, останется нажать «Подключить».

**Способ 2: вручную**

1. Telegram → **Настройки** → **Продвинутые настройки** → **Тип подключения** → **Прокси**
2. Добавь прокси типа **MTProto**:
   - **Сервер:** `127.0.0.1`
   - **Порт:** `1443`
   - **Secret:** из надписи в Termux

---

## 🛠 Команды

| Команда | Что делает |
|---------|-----------|
| `tgp` | Запустить прокси в окне |
| `tgp bg` | Запустить в фоне |
| `tgp stop` | Остановить |
| `tgp link` | Открыть Telegram с настройками |
| `tgp update` | Обновить прокси |

---

## ⚙️ Чтобы работало стабильно

- Не закрывай Termux свайпом из недавних приложений, сверни кнопкой «домой».
- В настройках Android → Приложения → Termux → Батарея выбери **«Без ограничений»**.
- Для работы без открытого окна используй `tgp bg`.

---

## ❓ Частые проблемы

**`tgp: command not found`**
Перезапусти Termux или выполни установку заново.

**В Telegram статус «Недоступно»**
Прокси не запущен. Запусти `tgp` и не закрывай Termux.

**`ModuleNotFoundError: No module named ...`**
Поставь модуль командой `pip install название_модуля`.

**Не грузятся фото и видео**
Попробуй запустить с другими настройками DC, описание есть в [оригинальном проекте](https://github.com/Flowseal/tg-ws-proxy).

## 🗑 Удаление

```bash
tgp stop
rm -rf ~/tg-ws-proxy ~/.tgproxy_secret $PREFIX/bin/tgp
```
